# 엘잭 게임 스킬 (LJack Game Protocol)
## 게임 런타임 하네스 엔지니어링 & 초자율 에이전틱 개발 프로토콜 (v1.0.0)

> **💡 시스템 지침 (System Directive)**:  
> 본 스킬은 게임 소프트웨어 제작 시 AI 에이전트가 기술적 결함(물리/충돌/무한루프/메모리)을 헤드리스 1만 틱 시뮬레이터로 스스로 100% 자가 치유하되,  
> **최종 패키징 배포 전 반드시 사용자에게 직접 조작감과 재미를 확인할 수 있는 [플레이어블 프리뷰 & 사용자 검수 관문 (Playable Review Gate)]을 열어 피드백을 수렴**하도록 규정하는 최상위 게임 개발 프로토콜입니다.

> **⚠️ 버전 독립성 불변 원칙 (Version Independence Principle)**:  
> **본 프로토콜의 버전(v1.0.0)과 대상 게임의 자체 버전은 완전히 별개입니다.**  
> 대상 게임은 사용자가 명시한 버전 또는 표준 SemVer 기본값(`v0.1.0` / `v1.0.0`)부터 온전히 독립적인 생명주기를 갖습니다.

## 1. 게임 런타임 하네스 엔지니어링 8대 핵심 기둥

게임 하네스(Game Harness)는 가변 프레임률, 불규칙한 키 입력, 물리적 충돌 오차 속에서도 게임 로직이 예측 가능하고 결정론적으로 구동되도록 감싸주는 **실행 및 시뮬레이션 뼈대**입니다.

```text
[입력 디바이스: 키보드/마우스/게임패드] ──> [입력 버퍼 큐 & Stuck 방지 가드]
                                                         │
┌────────────────────────────────────────────────────────▼──────────────────────────────┐
│                     게임 런타임 하네스 코어 (Game Runtime Harness)                    │
│                                                                                       │
│  1. 결정론적 고정 틱과 렌더링 분리 (Fixed 60Hz Tick vs Variable Delta Frame)           │
│  2. 헤드리스 1만 틱 시뮬레이터 (Headless 10k-Tick Sim Rig: 승패/밸런스 초고속 검증)    │
│  3. 입력 버퍼링 & 안전망 (Input Buffering, Coyote Time, 전역 키 릴리즈)               │
│  4. 충돌 감사 & 터널링 방지 (AABB, Raycast Sub-stepping)                              │
│  5. 게임 필(Game Feel) & 쥬스 (가변 점프, 낙하 가속, 히트스톱, 감쇄 스크린 셰이크)    │
│  6. ⭐ 플레이어블 검수 관문 (Playable Review Gate: 배포 전 사용자 직접 플레이 피드백) │
│  7. 세이브 데이터 스키마 버전 안전망 (Save State Migration Guard)                     │
│  8. 에셋 알파 무결성 & 원클릭 배포 (Sprite Alpha=0, HTML5 Web / Portable Package)     │
└────────────────────────────────────────────────────────┬──────────────────────────────┘
                                                         │
                      [검증 ALL PASS ➔ 사용자 플레이 검수 ➔ 최종 패키징]
```

- **기둥 1: 고정 틱과 렌더링 분리**: 물리와 게임 규칙은 Fixed $\Delta t$(60Hz)로 계산하고 렌더링 화면은 보간(Interpolation)으로 분리.
- **기둥 2: 헤드리스 1만 틱 시뮬레이터**: 화면 렌더링 없이 메모리 상에서 1만 번의 틱을 0.3초 만에 돌려 승패 도달 가능성, 점수, 메모리 안정성 자가 검증.
- **기둥 3: 입력 버퍼링 & 안전망**: 프레임 드랍 시 입력 씹힘 방지 및 게임 일시정지/종료 시 물리 입력 100% 해제.
- **기둥 4: 충돌 감사 & 터널링 방지**: 고속 투사체 관통 방지 서브스텝(Sub-step) 및 점프 모서리 걸림 보정.
- **기둥 5: 게임 필(Game Feel) & 손맛 튜너**: 코요테 타임(5틱), 점프 선입력 버퍼(5틱), 낙하 가속, 히트스톱 기본 탑재.
- **기둥 6: 플레이어블 검수 관문 (Playable Review Gate)**:
  - 헤드리스 검증 ALL PASS 완료 후, 최종 배포 전 반드시 로컬 실행 방법(`python run_game.py`)과 현재 밸런스 파라미터 요약표를 사용자에게 제시.
  - 사용자의 손맛/난이도 피드백을 반영하여 최종 승인(Approved) 시에만 배포 단계로 전진.
- **기둥 7: 세이브 데이터 버전 안전망**: 세이브 파일 JSON 포맷 변경 시 이전 데이터 자동 마이그레이션.
- **기둥 8: 에셋 알파 무결성 & 원클릭 배포**: 스프라이트 투명도(Alpha=0) 검증 및 원클릭 패키징.

## 2. 초자율 게임 에이전트 10대 실행 강령

1. **버전 독립성 준수**: 게임 프로토콜 버전(v1.0.0)과 대상 게임 고유 버전(`v0.1.0`)을 분리한다.
2. **기술 결함은 무중단 자가 치유한다**: 충돌 버그, 무한 루프, 문법 에러는 사용자에게 묻지 않고 1만 틱 러너로 스스로 해결한다.
3. **손맛과 재미는 반드시 사용자에게 검수받는다 (Playable Review Gate)**:  
   - 기술 테스트가 끝나면 **배포 전에 반드시 로컬 실행 스크립트와 밸런스 수치 요약표를 사용자에게 제출하고 직접 플레이 검수를 요청**한다.
   - 사용자 피드백(점프 높이, 적 스피드 등)을 수렴하여 파라미터를 튜닝한 뒤 최종 승인을 받는다.
4. **제로-토큰 스캐폴더 즉각 활용**: `scripts/game_scaffolder.py`를 즉시 호출하여 뼈대 코드 생성 토큰 15,000개를 아낀다.
5. **결정론적 고정 틱 원칙**: 프레임레이트(FPS)가 변해도 캐릭터 이동 속도와 물리 궤적은 100% 동일해야 한다.
6. **물리 터널링 절대 금지**: 고속 투사체는 서브스텝 충돌 검사를 의무 적용한다.
7. **5대 손맛 레시피 기본 탑재**: 코요테 타임, 점프 버퍼링, 낙하 가속, 히트스톱, 스크린 셰이크를 고려한다.
8. **임시 로그 소거 및 아티팩트 청결화**: 배포 전 임시 로그와 캐시 파일을 전면 소거한다.
9. **사용자 표면 UX 카피 정제**: 게임 내 UI(체력, 점수, 게임오버 문구)에 개발자 내부 용어가 노출되지 않도록 한다.
10. **선제적 게임 맹점 보고**: 완료 시 `[🔭 게임 밸런스 및 확장 제안 레이더]` 섹션을 의무 보고한다.

## 3. 개발자-AI 게임 페어 프로그래밍 6대 마법의 검증 질문

1. **손맛/조작감**: *"점프할 때 코요테 타임이나 선입력 버퍼링이 적용되어 있어 1프레임 차이로 조작이 씹히는 답답함이 없는가?"*
2. **물리 터널링**: *"캐릭터나 총알이 최고 속도로 벽이나 얇은 발판을 향해 돌진할 때 뚫고 지나가는 터널링 현상이 없는가?"*
3. **1만 틱 밸런스 내구성**: *"헤드리스로 1만 번 돌렸을 때 점수가 오버플로우되거나 클리어 불가능한 데드락 상태에 빠지지 않는가?"*
4. **난이도 곡선**: *"초반 30초와 후반 3분의 난이도 상승 곡선이 플레이어가 적응할 수 있는 공정한(Fair) 수준인가?"*
5. **플레이어블 검수 상태**: *"사용자가 지금 바로 `python run_game.py`를 쳐서 플레이해볼 수 있는 상태가 준비되었는가?"*
6. **배포 완성도**: *"패키징 시 불필요한 테스트 코드나 임시 파일 없이 단일 포터블 번들로 실행되는가?"*

## 4. 게임 자율 실행 6단계 표준 파이프라인

```text
[1단계: 게임 기획 승인 & 제로-토큰 게임 스캐폴딩]
  - 코어 규칙(이동, 목표, 패배 조건) 정의 ➔ scripts/game_scaffolder.py 호출 (토큰 15,000개 절약)
       ↓
[2단계: 헤드리스 1만 틱 시뮬레이터 & 충돌 하네스 구축]
  - 메모리 상에서 0.3초 만에 물리/상태 전이를 검증하는 10k-Tick 러너 구축
       ↓
[3단계: 게임 메카닉, 입력 버퍼 및 렌더링/손맛 구현]
  - Fixed 틱 물리 루프, 코요테 타임, 점프 선입력 버퍼, 타격 피드백(Juice) 탑재
       ↓
[4단계: 무중단 헤드리스 자가 치유 루프]
  - scripts/tick_sim_runner.py 가동 ➔ 1만 틱 시뮬레이션 ALL PASS (터널링 0건, 메모리 누수 0건)
       ↓
[5단계: ⭐ 플레이어블 프리뷰 & 사용자 검수 관문 (Playable Review Gate)]
  - scripts/play_preview_launcher.py로 조작법 및 밸런스 파라미터 요약 추출
  - 🎮 사용자에게 플레이 검수 요청 제출: "로컬에서 실행하여 손맛/난이도를 확인해주세요"
  - 🔄 사용자 피드백(속도/점프/패턴 미세 튜닝) 즉시 반영 ➔ 사용자 최종 승인(Approved) 획득
       ↓
[6단계: 원클릭 포터블 패키징 & 배포 완결]
  - 임시 파일 소거 ➔ 포터블/웹 번들링 ➔ 잠재 게임 확장 레이더 보고 후 완료
```
