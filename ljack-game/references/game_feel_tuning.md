# LJack Game Protocol: 게임 필(Game Feel) & 손맛 튜닝 가이드

플레이어가 "조작이 답답하다"거나 "게임이 엉성하다"고 느끼는 대부분의 원인은 그래픽이 아니라 **조작 반응성(Input Forgiveness)과 물리적 피드백(Juice)**의 결여에서 발생합니다.

LJack Game Protocol에서는 다음 5대 손맛 레시피를 기본 탑재하도록 권장합니다:

---

### 1. 코요테 타임 (Coyote Time: 낭떠러지 점프 유예)
- **문제**: 발판 끝에서 정확히 점프하려다 1프레임 차이로 허공에서 떨어져 조작감이 불쾌해짐.
- **해법**: 발판을 벗어난 직후 약 5~8틱(약 0.08~0.13초) 동안은 공중에 떠 있어도 점프 입력을 유효하게 인정.
```python
if is_grounded:
    coyote_timer = 6  # 6틱 동안 버퍼 유지
elif coyote_timer > 0:
    coyote_timer -= 1

if jump_pressed and (is_grounded or coyote_timer > 0):
    vy = jump_force
    coyote_timer = 0
```

---

### 2. 점프 버퍼링 (Jump Buffering: 착지 전 선입력)
- **문제**: 착지 직전에 점프 키를 미리 눌렀으나 착지 순간 키가 떼어져 점프가 씹힘.
- **해법**: 공중에 있을 때 점프 키가 눌리면 4~6틱 동안 "점프 예약" 플래그를 유지하고, 착지하는 즉시 자동으로 점프 발동.
```python
if jump_pressed:
    jump_buffer_timer = 6

if is_grounded and jump_buffer_timer > 0:
    vy = jump_force
    jump_buffer_timer = 0
```

---

### 3. 가변 점프 높이 & 낙하 가속 (Variable Jump & Fall Multiplier)
- **문제**: 점프 키를 살짝 톡 치든 길게 꾹 누르든 항상 똑같은 높이로 뛰면 캐릭터가 붕 떠 보임(Floaty).
- **해법**:
  - 점프 키를 떼었을 때 상승 중이라면 상승 속도를 즉시 절반으로 감속(`vy *= 0.5`).
  - 정점을 지나 하강(`vy > 0`)할 때는 중력을 1.5배~2배 강하게 적용하여 착지감을 묵직하게 형성.

---

### 4. 히트스톱 (Hitstop / Freeze-Frame: 타격 찰나 정지)
- **문제**: 공격이 적중했을 때 캐릭터와 적이 아무 저항 없이 스르륵 통과하면 타격감이 전무함.
- **해법**: 강한 타격 순간 2~5틱(0.03~0.08초) 동안 양쪽 스프라이트의 업데이트를 일시 동결하고, 이후 넉백 및 피격 이펙트 재생.

---

### 5. 감쇄 스크린 셰이크 (Decay Screen Shake)
- **문제**: 피격/폭발 시 화면이 딱딱하게 고정되어 있으면 충격량이 체감되지 않음.
- **해법**: 폭발 강도(Trauma)를 1.0으로 설정하고 매 틱마다 $0.9$배로 지수 감쇄시키며 카메라 오프셋에 난수 노이즈 반영:
```python
camera_offset_x = (random.random() * 2 - 1) * trauma * max_shake
trauma = max(0.0, trauma - 0.05)
```

---

### 6. 미세조정(Fine-Tuning) 요청 시 슬라이더 샘플 우선 출력 규격 (Fast-Path)
사용자가 신규 기능 추가가 아니라 **기존 수치·손맛·연출·속도·간격·밸런스의 미세조정**을 요청했다고 판단되면, 프로젝트 전체 빌드·다국어·릴리즈 닥터·패키징 절차를 거치지 않고 아래 규격의 **단일 인터랙티브 슬라이더 샘플**을 즉시 출력합니다.

1. **적용 과정 생략**: 사용자가 슬라이더로 확정값을 고르기 전까지 원본 프로젝트 파일 다중 수정, 1만 틱/E2E 전수 검증, 패키징을 선행하지 않습니다.
2. **샘플 필수 구성 요소**:
   - **실시간 프리뷰 캔버스/스테이지**: 대상 파라미터(예: 점프 궤적, 카드 호버 틸트/스캐터, 스크린 셰이크, UI 패딩, 애니메이션 커브)가 슬라이더 조작 즉시 반영되어 눈으로 체감 가능.
   - **슬라이더 컨트롤 (`<input type="range">`)**: 현재 프로젝트 기본값을 초기값(`value`)으로 두고 적절한 `min`/`max`/`step` 및 고정폭 숫자 리드아웃(`tabular-nums`) 제공.
   - **초기화 & 확정값 복사 버튼**: 기본값 리셋 버튼과, 확정된 파라미터를 JSON으로 클립보드에 복사(`Copy JSON`)하거나 바로 답변에 붙여넣을 수 있는 요약 박스 포함.
3. **출력 형태**:
   - `generative_ui` 인라인 위젯을 지원하는 환경: 컴팩트(`.html`, 권장 높이 ≤ 450px 인라인 임베드 또는 대시보드형 아티팩트)로 즉시 렌더링.
   - 일반 환경: 의존성 없는 단일 `.html` 샘플 파일을 생성/출력해 브라우저에서 곧바로 열어 조작할 수 있게 제공.
4. **확정 후 본 반영**: 사용자가 원하는 수치를 확정해 전달하면, 그 확정값만 대상 게임 코드에 반영하고 필요한 검증을 마칩니다.

---

### 7. 상태 알림(토스트) 대기열 적체 & 페이드인 지연 방지
- **문제**: 상태 안내나 에러 알림(토스트)을 긴 FIFO 대기열에 순서대로 쌓고 매번 페이드인(`alpha: 0 -> 1`) 애니메이션을 거치면, 플레이어가 조작한 뒤 알림이 한 박자 늦게 뜨는 듯한 답답한 반응감이 생깁니다.
- **해법**: 로그 히스토리가 목적이 아닌 단발성 상태 토스트는 새 메시지가 발생할 때 이전 대기열을 비우고 **페이드인 없이 `alpha = 1.0`으로 즉시 교체 표시**한 뒤, 짧게 유지하고 페이드아웃합니다.
