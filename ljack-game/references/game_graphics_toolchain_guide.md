# 🎨 게임 그래픽 종류별 실전 툴 나침반 & 구축 가이드
## (When to use What Tool - Game Art Pipeline)

인디 게임 개발 시 그래픽 에셋의 종류(UI, 일러스트, 도트, 이펙트)에 따라 **가장 가볍고 효율적인 툴을 선택하고 구축하는 실전 나침반**입니다.  
엄격한 해상도나 포맷 규칙에 얽매이지 않고, **어느 때에 어떤 도구를 써야 하는지** 직관적으로 파악할 수 있도록 정리되어 있습니다.

---

## 🧭 1. 그래픽 종류별 실전 툴 선정 나침반

```text
Q. 지금 만들려는 그래픽이 무엇인가요?
│
├── [A] 카드 틀, 테두리, 뱃지, 버튼, 게이지 바, 아이콘 (UI 에셋)
│     └── 👉 툴: Figma (무료 웹) + SVG 벡터 코드 + Game-icons.net
│           - 핵심: AI로 통짜 그림 그리지 말고, 가벼운 벡터(SVG)나 엔진 자체 9-패치로 뚝딱 만들기!
│           - 장점: 2~10 KB 초경량, 모바일~4K 절대 깨지지 않음, 밖으로 튀어나오는 돌출 뱃지 배치 자유자재.
│
├── [B] 카드 속 캐릭터, 몬스터, 보스 원화, 컷씬, 배경화 (고화질 회화/일러스트)
│     └── 👉 툴: SDXL 1.0 + ComfyUI (코랩 무료 GPU / Cloudflare 터널)
│           - 핵심: 프레임이나 글씨는 빼고 오직 "가운데 들어갈 일러스트 그림"에만 집중 투입!
│           - 장점: 832x1216 또는 1024x1024의 압도적인 3D/회화 질감과 깊이감.
│
├── [C] 2D 액션 캐릭터, 타일셋, 걷기/공격 프레임 (레트로 도트 감성)
│     └── 👉 툴: SD 1.5 + PixelArt LoRA + ControlNet ➡️ Aseprite / LibreSprite
│           - 핵심: AI로 1차 시트 뼈대를 잡고, Aseprite에서 도트 픽셀을 미세 다듬기.
│           - 장점: 32x32, 64x64 네이티브 도트 격자 일관성 유지.
│
└── [D] 마법진 회전, 포탈, 보석 반짝임, 피격 번쩍임 (살아 움직이는 효과)
      └── 👉 툴: 게임 엔진 2D 셰이더 (Shader 코드 3~5줄)
            - 핵심: 무거운 그림 대신 코드로 실시간 회전/발광(Glow) 연출!
            - 장점: 텍스처 용량 0 KB, 살아 숨 쉬는 게임다운 생동감.
```

## 🛠️ 2. 상황별 최적 툴 구축 및 연동 방법

### 1) UI 프레임 & 뱃지 제작 (Figma & SVG)
- **Figma (웹 기반, 설치 불필요)**:
  - 브라우저에서 바로 열고, AI가 작성한 SVG 코드를 `Ctrl+V`로 붙여넣으면 즉시 벡터 오브젝트로 편집 가능.
  - 마우스 드래그로 크기 조절, 색상 변경, 하스스톤식 돌출 뱃지 배치 테스트에 최적.
  - 완성 후 **[Export ➡️ SVG]**로 내보내어 Godot 4에 바로 드래그 앤 드롭.
- **Game-icons.net (무료 게임 아이콘 보물창고)**:
  - 칼, 방패, 포션, 하트, 해골 등 4,000개 이상의 게임 심볼을 SVG로 무료 제공.
  - 다운받아 카드 뱃지 중앙에 얹기만 하면 10초 만에 상용 UI 완성.
- **스타일 분기 팁**:
  - **리얼리스틱 판타지 (하스스톤 스타일)**: 금속 그라데이션, 베벨 하이라이트, 보석 림.
  - **캐주얼/만화풍 (슬레이 더 스파이어 스타일)**: 두꺼운 검은 먹선(8~14px), 단순하고 경쾌한 카툰 색상 블록.

### 2) 고화질 일러스트 제작 (SDXL + ComfyUI)
- **코랩(Colab) 무료 T4 GPU 세팅**:
  - 본체는 코랩 로컬 SSD(`/content/ComfyUI`)에서 3초 부팅.
  - 모델: `sd_xl_base_1.0.safetensors` (6.94GB) + `sdxl_vae.safetensors` (335MB).
  - VRAM 최적화 플래그: `--dont-upcast-attention --use-pytorch-cross-attention --listen`.
  - 터널: `cloudflared`로 안정적인 외부 접속 URL 확보.
- **주의할 점**: 프레임이나 글씨까지 AI에게 맡기지 말고, **카드 일러스트 창에 들어갈 캐릭터/배경 원화만** 렌더링하여 분리 투입할 것.

### 3) 2D 도트 스프라이트 제작 (SD 1.5 + Pixel LoRA)
- SDXL은 픽셀 격자를 뭉개버리므로, 도트 스프라이트에는 **SD 1.5 + PixelArtRedmond LoRA** 조합이 훨씬 정확합니다.
- ControlNet OpenPose로 8방향 걷기/대기 모션을 고정하고, `Aseprite`나 `LibreSprite`에서 프레임별 픽셀을 살짝 정리하는 워크플로우를 권장합니다.

### 4) 마법진 및 이펙트 (Godot 2D Shader)
- 무거운 그림을 돌리지 말고, 아래와 같은 셰이더 코드로 텍스처를 실시간 회전시킵니다:

```gdscript
// Godot 4 CanvasItem 회전 셰이더 예시
shader_type canvas_item;
uniform float speed = 1.0;

void fragment() {
    vec2 center = vec2(0.5, 0.5);
    vec2 uv = UV - center;
    float angle = TIME * speed;
    mat2 rot = mat2(vec2(cos(angle), -sin(angle)), vec2(sin(angle), cos(angle)));
    uv = rot * uv + center;
    COLOR = texture(TEXTURE, uv);
}
```

## 🏆 3. 상용 TCG 카드 레이어링 골든 룰 (Golden Rule)

카드는 절대 한 장의 평면 이미지로 만들지 않고, 3단계로 분업합니다:

```text
[Layer 1 - 바닥]  캐릭터 일러스트 (SDXL AI 원화 PNG)
      ▼
[Layer 2 - 중간]  카드 외곽 프레임 (가운데가 뚫린 SVG 벡터 창틀)
      ▼
[Layer 3 - 최상단] 밖으로 튀어나온 공격력/체력 뱃지 (SVG 벡터) + 동적 숫자 라벨
```

이 규칙만 지키면 어떤 인디 게임이라도 용량 부담 없이 가볍고, 4K 모니터에서도 선명하며, 게임 엔진에서 자유자재로 애니메이션을 넣을 수 있습니다!
